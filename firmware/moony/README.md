# Moony 固件 · 眼睛 + 耳朵 + 声音

在 `m0-eyes` 的基础上加了麦克风、喇叭和「摸头说话」。主板 MC03-F + XIAO ESP32-S3。

## 它会做什么

| 你做什么 | Moony 怎么回应 |
|---|---|
| 拍一下头顶（E0 短按） | 「咕」一声，眯眼笑 |
| 摸伞盖左 / 右边（E1 / E2） | 小啾一声，眼睛往那边上方看 |
| 1.5 秒内左右伞盖都摸到（顺着伞盖抚过去） | 低低的「呼噜」，眼睛半眯 |
| 摸脸颊（E3 / E4） | 害羞地「呜」，眼睛往下、往另一边躲 |
| 按住额头 2.5 秒（E5） | 打个哈欠睡着；点一下额头只是「嗯?」眨眨眼 |
| 戳侧身（E6 / E7） | 啾一声看过去；2.5 秒内戳 3 下 = 挠痒痒，咯咯笑着跳舞 |
| 拍拍背（E8 短按） / 手放背上 1.5 秒 | 「咕」/ 唱一段平静的旋律，眼睛半眯 |
| 碰底座（E9） | 「嗯?」往下看 |
| 点鼻尖（E10） | 「啵!」一声，眼睛睁大 |
| 摸后脑勺（E11） | 吓一跳，往上左右张望：谁在后面？ |
| 同时摸到 3 处以上（抱住） | 重逢小曲，眯眼笑 |
| 15 秒内拍头 5 下 | 好开心：唱重逢小曲，眼睛眯成一条缝 |
| 拍手 1 下 / 2–4 下 | 1 下：吓一跳；2–4 下：跟着啾回去同样的次数 |
| 用手挡住 ToF 窗口（脸上那个小方窗）一会儿再拿开 | 挡着的时候它也「闭眼躲起来」，拿开时「啵!」躲猫猫找到你了 |
| 有人站在面前 25 秒都没摸它 | 主动打招呼（每分钟最多一次） |
| 拿起来左右轻轻摇 3 下 | 开心的小颤音（用力晃还是会生气） |
| **按住头顶说话**，说完松手 | 眼睛往上看（在听）→ 眼珠转圈（在想）→ 回应 |
| 说口令 hello / sleep / wake up / look at me / dance / sing | 打招呼、闭眼睡觉、醒来、盯着你、跳舞、唱一段 |
| 说别的话 | 不用人话回答：用那句话的情绪家族换表情，唱一段**属于那句话**的旋律（同一句话唱同一段） |
| 一分钟没人以后有人走近 | 三个音的「重逢」小曲 |
| 拍手、突然很响 | 吓一跳，眼睛睁大 |
| 拿起来晃 / 倒过来 | 生气 / 晕 |
| 连不上热点或塔 | 照样眨眼、看人、被摸会笑；说话时只「嗯？」一下 |

## 没人理它的时候：自己的小生活

Moony 心里有三个慢慢变化的状态：**精力**（醒着大约 30 分钟会困）、**无聊**（一个人待着就涨，有人摸它、跟它说话、拍手就清零）、**好奇心**（自己飘来飘去）。安静下来以后，每隔 25–70 秒（有人在旁边时更久一点）它会自己做一件小事，声音都比平时轻：

- 哼一小段曲子
- 用「孢子语」自言自语（几个高高低低的咕哝音节）
- 东张西望
- 发呆、做白日梦（眼睛往上飘，飘一段梦幻的旋律）
- 一个人久了会叹气
- 偶尔打个喷嚏
- 十分钟内有人跟它说过话，它会想起来，再哼一遍那句话的旋律
- 累了又没人：打哈欠睡 2–4 分钟，自己醒来（被摸也会醒）

串口会打印「自己: …」。

睡着以后只有**摸它**或说「wake up」才会醒，走过的人不会吵醒它。

每次触发互动，串口会打印「互动: …」。如果摸伞盖左边时眼睛却往反方向看，在 `moony.ino` 顶部加一行 `#define TOUCH_GAZE_SIDE -1`。

## 声音

Moony 的嗓音是实时合成的「小动物声音」（思路来自 Pollen Robotics 的 Microduck）：7 个泛音、音高滑动、颤音、快速的嗡嗡抖动和一点气声，没有录音文件。现在用的是 1 号声音（种子 3，中心约 350 Hz，最圆润），参数在 `moony.ino` 的 `V_*` 常量里。改声音先在电脑上用 `scripts/moony-voice/voice.py` 试听。

事件声音：打招呼、被摸（咕）、在听（mm?）、在想（三声小哼）、没听懂（hm?）、看你（两声上扬）、开心、难过、拍手吓一跳、被晃（低吼）、倒过来（晕）、睡觉（哈欠）、醒来、重逢、没网、跳舞。

六个家族的旋律（用同一副嗓子唱）：tender 温暖慢板 · calm 低沉长音 · curious 明亮跳跃（断奏）· dreamy 全音阶飘浮带回声 · companion 三度和声 · lonely 小调往下沉。

## 烧录

1. 打开 `moony_config.h`，填上：
   - 手机热点的 `WIFI_SSID` / `WIFI_PASS`
   - Pi 的 `PI_HOSTNAME` / `PI_IP`（见 `scripts/moony-listen/README.md`）
   - 说话用的触摸电极 `TALK_ELECTRODES`（默认 E0）
2. Arduino IDE：开发板 **XIAO_ESP32S3**，USB CDC On Boot **Enabled**，**PSRAM: OPI PSRAM**（要开，不然录音只有 3 秒）。
   arduino-cli：`--fqbn esp32:esp32:XIAO_ESP32S3:CDCOnBoot=default,PSRAM=opi`
3. 库：Adafruit GFX、Adafruit SSD1306、Adafruit_VL53L0X（和 m0-eyes 一样）。
4. 上传。开机会「叮」一声。

## 串口（115200）

- `1`–`6`：直接播放六个家族的旋律（不用联网，先听听喇叭）
- `v`：按顺序试听 16 个事件声音（每按一次换下一个，串口会打印名字）
- `i`：状态（Wi-Fi、Pi 地址、触摸、麦克风音量、当前动作）
- `p`：重新找 Pi
- `d`：打印距离和麦克风音量
- `t`：触摸监视。每 0.25 秒打印 12 路的信号 `E0:  3 …`，摸到的那路数字变大并带 `*`，同时打印「摸到: E3」。再按 `t` 关
- `e`：触摸监视只看一路。每按一次换下一路（E0 → E1 → … → E11 → 全部），会显示一条进度条，`|` 是触发门槛
- `c`：重新校准测距背景
- `n` / `h` / `z` / `s` / `a`：手动切表情

## 测试顺序

1. **不联网：** 按 `1`–`6` 听旋律；摸 E0 短按听「啾」；拍手看眼睛睁大。
2. **连上热点：** 串口出现「Wi-Fi 已连上」；按 `p` 能解析到 Pi。
3. **Pi 上跑 `moony_listen.py --debug`：** 按住 E0 说「hello」，Pi 打印转写，Moony 唱上行琶音。
4. **说一句心情：** 比如「I miss my family」，Pi 打印 `reading lonely …`，Moony 换表情、唱小调。

> 我这边没法编译 ESP32，只在电脑上用模拟的 Arduino 头文件做过语法和旋律检查。第一次编译如果有报错，把报错贴回来就行。
