# 面包板验货程序

## 用法
1. Arduino IDE 装好 esp32 板包,开发板选 `ESP32 Dev Module`
2. 打开 `bench-check.ino`,选好串口,上传
3. 串口监视器波特率设 **115200**,每 3 秒刷新一次扫描结果

## 预期输出
只插了屏1:
```
--- 扫描 I2C 总线 ---
  0x3C  SSD1306 屏1
  共 1 个设备
```
五个都插上(屏2 已改 0x3D):
```
  0x29  VL53L0X 测距
  0x3C  SSD1306 屏1
  0x3D  SSD1306 屏2
  0x5A  MPR121 触摸
  0x68  MPU6050 姿态
  共 5 个设备
```

## 排错
| 现象 | 原因 |
|---|---|
| 一个都扫不到 | VCC/GND 接反、SDA/SCL 插错脚、模块没供电 |
| 只少某一个 | 那个模块的 4 根线单独再对一遍 |
| 两块屏只出现 0x3C | 屏2 地址电阻没改到 0x7A 侧 |
| 地址乱跳/时有时无 | 杜邦线接触不良,或总线太长 |

屏幕显示测试:把 `TEST_SCREEN` 改成 `1`(需先在库管理器装 `Adafruit SSD1306` + `Adafruit GFX`),屏1 上会画一个方框和 MYCELIUM 字样。
