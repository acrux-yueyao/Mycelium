# 声音链验货(阶段2)

屏幕点亮之后再做这一步。不需要装任何库,用的是 ESP32 板包自带的 I2S 驱动。

## 接线(和电路图下半张一致)

| 模块 | 引脚 | ESP32 |
|---|---|---|
| INMP441 麦 | SCK / WS / SD | G14 / G15 / G32 |
| | VDD / GND | 3V3 / GND |
| | **L/R** | **GND(不接就没信号)** |
| MAX98357A 功放 | BCLK / LRC / DIN | G26 / G25 / G27 |
| | VIN / GND | 3V3 / GND |
| | GAIN / SD | 悬空不接 |
| 3020 喇叭 | + / − | 功放的 + / − 焊盘 |

## 预期

上电即播一段音阶(do re mi fa so),然后串口每 120ms 打一行音量表:

```
   312 |#
  8420 |####################
```

安静时数字小、条短;对着麦说话或吹气,条明显变长。

## 串口按键(115200)
- `t` 再播一次音阶
- `b` 播一声哔
- `m` 开关音量表

## 排错

| 现象 | 原因 |
|---|---|
| 完全没声 | 喇叭线没焊牢 / VIN 没供电 / DIN 接错脚 |
| 有声但很小 | 正常,3V3 供电下 3020 音量有限;可把功放 VIN 改接 5V(VIN 耐 5.5V) |
| 沙沙底噪大 | GND 没共地,或音频线和电源线捆在一起 |
| 音量表恒为 0 / 报"麦无数据" | L/R 没接地、SD 接错脚、麦 VDD 接了 5V(只能 3V3) |
| 音量表数字乱跳很大 | 麦离喇叭太近形成回授,把两者分开 20cm 再测 |
