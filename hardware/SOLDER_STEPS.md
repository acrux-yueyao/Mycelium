# MC02-AB 焊接实操 · 一步一步

配合 `mc02_ab_sheet.png`(布局)和 `SOLDERING.md`(手法)。
每步末尾的 **✓** 是验收标准,不过就停下,别带病前进。
每关结束拍张照发我,我帮你看焊点再进下一关。

---

## 第 0 关 · 开工准备(10 分钟)

1. 桌面清空,电池放到**另一张桌子**——今天所有步骤都不碰电池
2. 烙铁 330°C(有铅)/ 370°C(无铅),海绵微湿,烙铁头上锡到发亮
   ✓ 烙铁头亮银色,不是黑的
3. 摆出:洞洞板 18×24、排针排母、28AWG 硅胶线(红黑 + 杂色)、
   松香、吸锡带、斜口钳、万用表
4. 万用表拧到蜂鸣挡,表笔互碰
   ✓ 会响

## 第 1 关 · 模块插排针(每个 5 分钟)

对象:MAX98357A(5 针)、MPU6050(前 4 针)、MPR121(4 针)。
屏、ToF、麦你在面包板阶段已经焊过排针,跳过。

5. 排针**长脚朝下**插进面包板当夹具,模块扣上去
6. 只焊**对角一个脚**,拿起来看正不看歪
   ✓ 模块与排针垂直;歪了就加热那一脚扶正
7. 焊其余脚:烙铁头同时贴住焊盘和针脚 1 秒 → 送锡 → 再停 1 秒抽走
   ✓ 每个焊点是小火山锥,不是圆珠;不连邻脚
8. 每个模块焊完:蜂鸣挡量 VCC↔GND
   ✓ 不响(响 = 短路,先找锡桥)

## 第 2 关 · 面包板验声(落板前最后一次验货)

MAX98357A 和 INMP441 是仅剩没验过的模块,必须先活再落板。

9. WROOM-32 接功放:3V3→VIN · GND→GND · G26→BCLK · G25→LRC · G27→DIN;
   喇叭两根线拧上功放 +/−(先不焊死)
10. 接麦:3V3→VDD · GND→GND · G14→SCK · G15→WS · G32→SD · L/R→GND
11. 烧录 `firmware/bench-audio/`(工具链和 m0-eyes 一样,选同一块口)
    ✓ 上电:喇叭出一串上行音阶
    ✓ 串口监视器 115200:对麦说话,电平条随声音跳
12. 有问题按 SOLDERING.md 第 6 节排;两个都绿了才拆面包板

## 第 3 关 · 合板准备(15 分钟)

13. 洞洞板四角,距两边各 3mm(约第 2 孔位)用 2mm 钻头/锥子扩 M2 孔
14. 空板放上背板四柱,M2 螺丝拧两颗对角
    ✓ 板平贴柱顶,孔位不别劲;不合就锉孔,别硬拧
15. 记号笔在**元件面**照布局图画出各模块地盘和 5 个插座位
    (元件面 = 朝腔内那面;XIAO 在顶部居中,USB 朝上)
    ✓ 和 mc02_ab_sheet.png 左图一致,J3 在左上角

## 第 4 关 · 母线(30 分钟,全板的骨架)

板中缝走 4 条竖母线(镀锡裸线,行 2 拉到行 16):
3V3、GND、SDA0、SCL0。

16. 剪 4 段裸线拉直,穿孔贴板面,每 3-4 孔点焊一个锚点
17. 母线之间**互相不许碰**;交叉处必须一根从孔背面绕
    ✓ 蜂鸣挡两两互量 6 组组合,全部不响
18. 在 GND 母线尾端焊一小段线头做"公共测试点"
    ✓ 后面每焊一步都拿它当参考量短路

## 第 5 关 · 排母与模块落板(1 小时)

19. **XIAO 先处理底面**:两根 28AWG(红/黑)焊到底面 BAT+/BAT− 小焊盘,
    焊点低平,加一滴热熔胶做应力释放
    ✓ 轻拽不动;蜂鸣挡 BAT+↔BAT− 不响
20. 两条 7P 排母焊在 XIAO 地盘(先对角一脚校垂直,同第 1 关手法)
    ✓ XIAO 插拔顺畅,BAT 线从排母间垂出不被夹
21. MAX98357A、MPU6050、MPR121 依次落板(排针直接穿孔焊背面)
    **MPU6050 板上箭头 X 指向右手边**——姿态轴就靠它
    ✓ 每落一个:VCC 脚↔GND 母线不响
22. 五个插座落板:J2/J4/J5 沿下缘,J1 右上、J3 左上(排针即可)
23. 飞线把每个模块接上母线,照这个表(逐根,焊完打勾):

| 从 | 到 |
|---|---|
| XIAO 3V3 | 3V3 母线 |
| XIAO GND | GND 母线 |
| XIAO D4 / D5 | SDA0 / SCL0 母线 |
| XIAO D0 / D7 | J3 的 SDA1 / SCL1 脚(直飞,不走母线) |
| XIAO D2 / D1 / D3 | MAX BCLK / LRC / DIN |
| XIAO D8 / D9 / D10 | J2 的 SCK / WS / SD 脚 |
| XIAO D6 | J5 的 DIN 脚 |
| XIAO BAT+ / BAT− 线 | J4 的 + / − 脚(= 电池轨) |
| MAX VIN·GND | 3V3·GND 母线 |
| MPU VCC·GND·SDA·SCL | 3V3·GND·SDA0·SCL0 |
| MPR VCC·GND·SDA·SCL | 3V3·GND·SDA0·SCL0 |
| J1 四脚 | 3V3·GND·SDA0·SCL0 |
| J2 VDD·GND | 3V3·GND |
| J3 3V3·GND·SDA0·SCL0 | 对应母线 |
| J5 5V·GND | J4 电池轨 + · GND 母线 |

    ✓ 全表焊完:3V3↔GND 不响;SDA0↔SCL0 不响;电池轨+↔GND 不响

## 第 6 关 · 电源链(重要,只有一种对的接法)

原则:**电池只连两处——J4 电池轨 和 TP4057 的 B±**。
TP4057 的 OUT+/OUT− 空着;XIAO 由 BAT 焊盘供电(第 23 步已接轨)。

24. H5 线:J4 电池轨 → TP4057 `B+`/`B−`(红对 B+,黑对 B−)
25. 蜂鸣挡最后大检:B+↔B− 不响;B+↔GND 母线**响**才对
    (电池轨负极和 GND 共地,正极对地不通)
    ✓ 上面两条都符合
26. **先不接电池。**插 XIAO 的 USB:
    ✓ 3V3 母线对 GND 量出 3.3V;各模块摸 3 秒不烫

## 第 7 关 · 远端件与线束(1 小时)

27. H3(6芯 110mm):一端 6P 杜邦壳对 J3,另一端焊双屏——
    左屏 SDA/SCL 接 SDA0/SCL0 芯,右屏接 SDA1/SCL1 芯,3V3/GND 共享
28. H1(4芯 70mm):J1 → ToF;H2(5芯 70mm):J2 → 麦(L/R 在模块上已接地)
29. H6:喇叭两线焊 MAX 的 +/− 焊盘(这次焊死)
30. H7(可选):J5 → WS2812 段,认箭头方向
    ✓ 每根线束两端拽一下不脱;同色对同名

## 第 8 关 · 上电验收(全绿 = 内舱电子完工)

31. 只插 USB(仍无电池),烧双总线扫描(bench-check)到 XIAO
    **注意引脚映射选 XIAO 版**(总线0 = D4/D5,总线1 = D0/D7)
    ✓ 总线0:0x3C · 0x29 · 0x68 · 0x5A;总线1:0x3C
32. 烧 bench-audio(XIAO 引脚版):
    ✓ 喇叭音阶响;串口电平条随说话跳
33. **电池到货日**:万用表量插头,红=+;对照 TP4057 丝印;
    接 J4 → 拔 USB
    ✓ 整机由电池点亮;TP4057 插 USB-C,充电灯亮
34. 收尾:热熔胶点住所有飞线根部;拍全板正反面照片存档
