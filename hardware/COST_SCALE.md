# 铺开大货 · 成本测算

接 COST.md(单只 $93)。大货不是"单只 × N"——结构会变三次:
模块换贴片板、磁铁走批发、外壳从打印转注塑。每一次都有门槛和代价。

样本仍是 284 颗方块的机型。

## 四、外壳:这里有个结构性矛盾

### 打印农场

| | |
|---|---|
| 料(538g,大宗 PLA $16/kg) | $8.6 |

### ⚠️ 但注塑和这个产品的内核冲突

方块是**按句子生成**的:每句话的方块朝向组合都不一样,40 种变体的配比每只都不同。
开模开的是"变体",可变体本身不固定 —— **没法为一个生成式外形开模。**

三条出路:

1. **通用方块 + 盲塞**(推荐):方块六面全带耦合特征,只开**一副方块模 + 一副小盲塞模**。
   拼装时朝外的面塞一颗盲塞(平的小圆片),外表面照样是平的。
   一套模具通吃所有句子,而且"塞盲塞"这个动作本身可以变成拼装仪式的一部分。
   代价:多一个零件、用户多一道工序。
2. **接受外露特征**:六面通用、不塞盲塞,把榫卯点当成表面纹理(乐高的凸点就是这么变成标志的)。
   零成本,但违反你定的"朝外不能有凹凸"。
3. **只注塑核心舱,方块继续打印**:核心舱本来就是冻结件、一个 SKU、天生适合开模
   (模具约 $3-5k,省 48g 打印和 2 小时机时)。方块保持打印,保住生成式的纯粹。
   **这是 500 只以下最合理的选择。**

## 五、表里没算的钱(卖之前必须过一遍)

| 项 | 量级 | 说明 |
|---|---|---|
| **无线认证 FCC/CE** | $3,000-8,000 一次性 | 用预认证的 WROOM 模组能省一大截,但整机仍要测非预期辐射。**跑不掉。** |
| **锂电池 UN38.3 + MSDS** | $1,500-3,000 一次性 | 带电池发货的硬门槛,空运尤其严 |
| 包装 + 说明书 | $3-6/只 | 284 颗方块要分格盒,不是塑料袋能糊弄的 |
| 不良与返修 | 售价 3-5% | 屏幕和电池是重灾区 |
| 物流 | $8-15/只 | 整机约 1.2kg,带电池运费溢价 |
| 客服/退货 | 售价 5-8% | 用户自己拼装 = 拼错求助率高 |

**一次性投入合计约 $6k-14k**(NRE + 认证 + 模具),这笔钱决定了最小起订规模。

## 六、结论

- **50 只以内**:维持现状,单只 $110,不用改任何设计。适合小批量发售或展览。
- **100-500 只**:先做两件事——磁铁走批发(省 $14)、核心舱开模(省几小时机时)。
  外壳继续打印,单只落到 **$60-70**。这是最舒服的区间:不用改设计,不用碰认证以外的大钱。
- **1,000 只以上**:必须出 PCB、必须解决外壳的生成式矛盾(通用方块+盲塞),
  单只 **$49**,但要先掏 $6k-14k 一次性,并且**要重新设计一次方块**。
- **定价参考**:硬件类众筹通常按落地成本 2.5-3.5 倍定零售价。
  $49 的成本对应 **$130-170** 零售——考虑到这是个"一句话生成一只、全世界只有一只"的产品,
  这个价位站得住。

**最大的单点风险不是成本,是那 28 小时打印工时。** 先把它测准,别的都好说。
