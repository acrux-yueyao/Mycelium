# MC02 载板 v1 · 原理图需求

把现在 18×24 洞洞板上的手工飞线换成一块定制 PCB。**接法和洞洞板完全一致,固件不改。**
原理图见 `schematic_v1.png`(由 `schematic_v1.py` 生成,改接法只改那个文件)。
这份文档给画板的人看:看完就能在立创 EDA 里画原理图、布板、下单。

---

## 1 · 目标

| 项 | 要求 |
|---|---|
| 用途 | 取代洞洞板 + 飞线;模块照旧,只是从"飞线连接"变成"走线连接" |
| 板框 | **46 × 61 mm**,与洞洞板相同 |
| 安装孔 | 4 × M2(Ø2.2 孔),孔心离板边 3 mm → 孔距 **40 × 55**,对 MC02-P 背板的 4 根柱 |
| 板厚 | **0.8 mm**(洞洞板约 1.6) |
| 层数 | 两层;底层整面铺 GND |
| 元件面 | 朝腔内那面;XIAO 在上部居中,USB-C 朝板上边(和洞洞板一样) |
| 固件 | 不改:引脚映射同 `SOLDERING.md` §3 |

v1 刻意保守:模块全部沿用(XIAO、MPR121 板、GY-521 板),先验证"走线 + 连接器"没问题。
把芯片直接画到板上(更薄)是 v2 的事,见第 7 节。

## 2 · 网络表(画原理图照这个连)

同名网络连在一起。NC = 不连。

| 网络 | 连接的引脚 |
|---|---|
| **3V3** | U1.3V3 · U2.3V3 · U3.VCC · J1.1 · J2.1 · J3.1 · JP1(默认侧) |
| **GND** | U1.GND · U1.BAT− · U2.GND · U3.GND · J1.2 · J2.2 · J3.2 · J4.− · J5.2 · J6.2 |
| **VBAT** | U1.BAT+ · J4.+ · J5.1 · JP1(备选侧) |
| **VBUS** | U1.5V → 只接测试点 TP1(不供任何东西) |
| **SDA0** | U1.D4 · U2.SDA · U3.SDA · J1.3 · J3.3 |
| **SCL0** | U1.D5 · U2.SCL · U3.SCL · J1.4 · J3.4 |
| **SDA1** | U1.D0 · J3.5 |
| **SCL1** | U1.D7 · J3.6 |
| **I2S_BCLK** | U1.D2 · J6.3 |
| **I2S_LRC** | U1.D1 · J6.4 |
| **I2S_DIN** | U1.D3 · J6.5 |
| **MIC_SCK** | U1.D8 · J2.3 |
| **MIC_WS** | U1.D9 · J2.4 |
| **MIC_SD** | U1.D10 · J2.5 |
| **LED_DIN** | U1.D6 · J5.3 |
| J6.1(功放 VIN) | 经 JP1 选 3V3(默认)或 VBAT |
| E0–E11 | U2 的 12 个电极脚 → J7.1–12 |
| NC | U2.IRQ · U2.ADD(悬空 = 0x5A)· U3.XDA · XCL · AD0(悬空 = 0x68)· INT |

I2C 地址检查:总线 0 = 左屏 0x3C · ToF 0x29 · MPU 0x68 · MPR121 0x5A,互不冲突;
总线 1 = 右屏 0x3C 独占。两块屏都是 0x3C,所以必须分两条总线,别合并。

## 3 · 元件清单

| 位号 | 元件 | 封装 / 说明 |
|---|---|---|
| U1 | Seeed XIAO ESP32-S3 | **邮票孔贴焊(已定)**:用 Seeed 官方 XIAO 封装库的 SMD 版,14 个邮票孔焊盘,XIAO 平贴板面直接焊,不用排母。底面 BAT+/BAT− 见 §3.1 |
| U2 | MPR121 触摸模块(你现在那块) | 按模块实际孔位画 6P 排针孔:3V3·IRQ·SCL·SDA·ADD·GND;模块平贴板面,低排针或直接焊 |
| U3 | MPU6050 GY-521 模块 | 8P 排针孔:VCC·GND·SCL·SDA·XDA·XCL·AD0·INT;**丝印画箭头标 X 轴朝右**(姿态方向靠它) |
| J1 | ToF 连接器 4P | 走线到前壁 W 窗块后的 VL53L0X |
| J2 | 麦克风连接器 5P | 到 M 孔块后的 INMP441(L/R 在模块上已接地) |
| J3 | 双屏连接器 6P | 到眼罩里的两块 GME12864-11 |
| J4 | 电池连接器 2P | 603040 锂电;同一组焊盘再引两根线去 TP4057 的 B+/B−(TP4057 不上板,照旧贴腔底) |
| J5 | 灯带连接器 3P(可选) | WS2812B 3–5 颗 |
| J6 | 功放连接器 5P | MAX98357A 照旧贴在腔底喇叭旁,不上板 |
| J7 | 触摸电极 12P | MPR121 E0–E11 引出,去铜箔电极;可以只装用到的几路 |
| JP1 | 3 焊盘跳线 | 功放供电选择,默认短接 3V3 侧 |
| C1 / C2 | 10 µF / 100 nF | 0603/0805,紧靠 U1 的 3V3 脚 |
| C3 | 100 µF | 紧靠 J6,给功放瞬时电流 |
| R1–R4 | 4.7 kΩ 上拉 | SDA0/SCL0/SDA1/SCL1 各一个,**预留不贴**——屏、ToF、MPU、MPR 模块都自带上拉 |
| TP1 | 测试点 | VBUS |

### 3.1 · XIAO 贴焊的封装要求

1. **USB-C 对齐板上边**:XIAO 的 USB-C 口和载板上边缘齐平(或伸出 0.5 mm),插线不被板挡住。
2. **底面电池焊盘**:XIAO 背面的 BAT+/BAT− 贴焊后压在载板上,烙铁够不着。载板在这两个焊盘
   正下方各开一个 **Ø1.0 mm 金属化通孔**:焊完邮票孔后,从载板背面往孔里送锡,锡会流上去
   连住 XIAO 的焊盘。这两个孔分别接 VBAT 和 GND。
3. **XIAO 底下除了这两个孔,全部盖阻焊**:不走裸铜、不放过孔焊盘。XIAO 背面还有别的测试焊盘,
   碰到裸铜会短路。
4. 丝印画出 XIAO 外框和 USB 方向箭头,贴的时候对准用。

**连接器选型:** 建议全部用 **JST SH 1.0 mm 卧式**(立创有现货,也能让嘉立创贴)。
它比现在的 2.54 弯排针矮一半以上,和"做薄"的目标一致;线束换成 SH 1.0 端子线,
两端都做成可拆。如果想先沿用手上的杜邦线,就画 2.54 卧式排针孔位,v1 也能用。

## 4 · 电源(只有一种对的接法)

- 电池只接两处:**J4(→ VBAT 网络 → XIAO 底面 BAT+)** 和 **TP4057 的 B±**。
- XIAO 自带充电管理和 3.3 V 稳压,整板 3V3 由 XIAO 输出,不另加稳压。
- TP4057 的 OUT± 不接。腔底的 USB-C(对 U 块槽)只用来充电。
- 两路充电(XIAO 的 USB、TP4057 的 USB-C)不要同时插。
- 功放默认吃 3V3;音量不够再把 JP1 改到 VBAT(MAX98357A 允许 2.5–5.5 V)。
- WS2812 吃 VBAT(3.7–4.2 V,短灯带够用)。

## 5 · 布板要求

1. **天线**:XIAO ESP32-S3 用随附的外接 FPC 天线(U.FL 座在 XIAO 板上)。U.FL 座上方
   别放高元件,留出插拔空间;天线片贴到腔壁,远离电池和磁铁密集处。
2. I2S 两组(功放 J6、麦克风 J2)走线短、远离 VBAT 粗线;MIC_SD 和功放线不要平行长走。
3. I2C 四根尽量成对走;总线 1 只去 J3,不要和总线 0 并到一起。
4. 3V3、VBAT 线宽 ≥ 0.5 mm;信号 0.2–0.25 mm。
5. 底层整面 GND,顶层空白处也铺 GND,多打过孔缝合。
6. 4 个 M2 孔周围 Ø5 mm 内不走线(螺丝头和柱子)。
7. 连接器 J1–J6 开口朝板边,线往板外出(和现在弯排针的出线方向一致);
   J3 左上角、J1 右上角、J2/J6/J5/J4 下缘——沿用洞洞板布局,线束长度就不用改。
8. 丝印:每个连接器标网络名(例:`J3 3V3 GND SDA0 SCL0 SDA1 SCL1`),第 1 脚打方框。
9. **高度预算**:腔体给板子上方 21 mm。XIAO 贴焊后只高约 4.5 mm(USB-C 口最高),比排母方案
   矮约 8 mm,腔里多出来的空间可以留给线束。板子下面还要放电池,背板柱子 `BOSS_H` 暂不改。

## 6 · 嘉立创下单参数(第一版)

| 项 | 选 |
|---|---|
| 层数 | 2 |
| 板厚 | 0.8 mm |
| 尺寸 | 46 × 61 mm |
| 数量 | 5 |
| 阻焊 | 随意(绿最快最便宜) |
| 表面处理 | **沉金**(焊盘平,邮票孔贴焊好对齐) |
| 贴片 | **半贴**:嘉立创只贴小件(C1–C3、JST SH 连接器 J1–J7),5 片里贴 2 片;R1–R4 不贴。XIAO、MPR121、GY-521 自己焊 |

需要交给嘉立创的文件:Gerber(光绘)+ BOM + 坐标文件(CPL),立创 EDA 都能一键导出。
BOM 里的电容、连接器尽量从立创商城现货里选(基础库免上料费)。

**谁焊什么:**

| 元件 | 谁焊 | 原因 |
|---|---|---|
| C1–C3、J1–J7(JST SH 1.0) | 工厂 | 1.0 mm 间距的贴片连接器手焊容易连锡,工厂贴最稳 |
| XIAO(邮票孔) | 自己 | 模块不在嘉立创元件库;手焊邮票孔不难 |
| MPR121、GY-521 模块 | 自己 | 同上,网购模块工厂没有料 |
| 两个 BAT 通孔 | 自己 | 焊完 XIAO 从背面送锡 |

## 7 · 拿到板子后的验收(和洞洞板第 8 关相同)

1. 不焊任何东西,蜂鸣挡量:3V3↔GND、VBAT↔GND、SDA0↔SCL0、SDA1↔SCL1 全部**不响**
2. **XIAO 焊上去之前先单独验货**(焊上就拆不下来):单独插 USB 烧 `bench-check`,串口有输出才焊
3. 焊 U1:邮票孔先焊对角两个焊盘定位 → 检查 USB 对齐板边 → 焊其余 12 个 → 从背面给两个
   BAT 通孔送锡。焊完插 USB:3V3 对 GND 量出 3.3 V;蜂鸣挡 VBAT↔GND 不响
4. 焊 U2、U3,插 J1、J3,烧 `bench-check`(XIAO 版):总线 0 报 0x3C·0x29·0x68·0x5A,总线 1 报 0x3C
5. 接 J2、J6,烧 `bench-audio`:喇叭音阶响,串口电平条随说话跳
6. 最后接电池(先量极性),拔 USB:整机由电池点亮

## 8 · v2 方向(验证 v1 后再做)

把模块换成芯片直接画上板,整板可以再薄、再小:

- MPR121 模块 → MPR121 芯片(QFN-20)+ 外围
- GY-521 → 一颗现货的 6 轴 IMU(MPU6050 已停产,换型号要改固件驱动)
- MAX98357A 模块 → 芯片上板,喇叭直接焊到板上
- 可选:XIAO → ESP32-S3 模组 + 自己的充电/稳压电路(最薄,但设计难度和风险最高)

v2 需要一位有贴片经验的硬件工程师把关,第一版先用 v1 跑通。
