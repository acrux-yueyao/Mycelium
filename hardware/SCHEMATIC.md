# MC03-F 脸板 v1 · 定制 PCB

所有机器人共用的一块主板。它贴在脸皮后面,填满 5×6 格(60×72)的机身空腔,
取代 18×24 洞洞板 + 飞线。**接法与洞洞板一致,固件不改**(引脚表见 `SOLDERING.md` §3)。

| 文件 | 说明 |
|---|---|
| `pcb/facebrd_gen.py` | 生成器:摆件 → 自动布线(Freerouting)→ 铺地 → DRC → 导出。改板只改它 |
| `pcb/out/facebrd.kicad_pcb` | KiCad 7 工程,可以打开看 3D / 手改 |
| `pcb/out/facebrd_gerber.zip` | **嘉立创下单文件**(Gerber + 钻孔) |
| `pcb/out/facebrd_bom.csv` · `facebrd_cpl.csv` | 贴片用 BOM / 坐标文件(嘉立创格式) |
| `pcb/out/facebrd_top.png` · `_bottom.png` | 正反面预览 |
| `pcb/out/facebrd_drc.txt` | 规则检查报告:0 未连接 · 0 电气违规(剩下的都是丝印压焊盘之类的外观项) |

## 1 · 板子

| 项 | 值 |
|---|---|
| 外形 | 56 × 68 mm,圆角 R5;顶边中央 9 × 19 的缺口给 XIAO |
| 安装 | 4 × M2,孔距 40 × 55 —— 和 MC02-P 背板现有的 4 根柱完全一样 |
| 层/厚 | 两层 · **0.8 mm** · 背面整块地平面,正面只走线(可读,不碎) |
| 线宽/间距 | 0.25 / 0.15 mm,过孔 0.6/0.3(嘉立创两层板能力 0.127,留了余量) |
| 坐标系 | 原点 = 空腔中心(机器人坐标 x=90, y=60);正面(F.Cu)朝脸皮 |
| 位置 | 板正面距脸皮背面 ≥ 4.5 mm(XIAO 的 USB-C 口最高);板背后放电池 |

**背板改为门板 MC04-D**(`door_gen.py`,2026-10-07):不再用 84×84 的平板。门板是填满空腔开口的
60×72×12 空心盒,外面是 5×6 马赛克(同列皮肤颜色,异色为嵌片),四周 8 个磁铁+销钉吸在空腔内壁的
8 颗锚定方块上(这 8 颗由 kit_cubes 自动加耦合面,tag=door)。板子用 4 根 Ø6 柱子立在门板内侧
(柱高 17.1,板面离脸皮背面 5.3 mm),电池躺在门板里。整块门板连板带电池一起拔出,插 USB 烧录。
门板磁铁极性与方块同规则:门板的左壁 N、右壁 S、下壁 N、上壁 S(方块坐标)。MC02-P 作废。

**W 窗 / M 孔的位置从此固定**(所有机器人共用):ToF 窗 = 舱区第 3 列第 2 行,麦克风孔 = 第 2 列第 3 行
(`kit_cubes.py` 已改成固定格,四个测试形状上这两格都是露出的皮)。moony 现在的 W/M 在别处,
换这块板时要重打 4 颗:新位置的 W、M 各 1 颗,旧位置换回普通 C-33 各 1 颗。

## 2 · 板上有什么

| 位号 | 元件 | 谁焊 | 说明 |
|---|---|---|---|
| U1 | XIAO ESP32-S3 | **自己焊**(嘉立创不备货;C48405120 是 nRF52840 Plus,别选) | 邮票孔贴焊,USB-C 与板顶边齐平。**BAT± 走缺口**:XIAO 背面的电池焊盘正好露在缺口里,两根短线从缺口穿到板背面,焊到 TP2(BAT+)/ TP3(BAT−) |
| U2 | MPR121QR2 触摸芯片 | 工厂(C91322) | 代替触摸模块;ADDR 接地 = 0x5A;12 路电极引到 J7。引脚:1 IRQ 2 SCL 3 SDA 4 ADDR 5 VREG 6 VSS 7 REXT 8–19 ELE0–11 20 VDD;封装 QFN-20 3×3 0.5 mm,自绘(KiCad 库里没有不带角脚的) |
| U3 | MPU-6050 姿态芯片 | 工厂(C24112) | 代替 GY-521;AD0 接地 = 0x68;丝印 `X ▶` 指向机器人右手 |
| C1–C9, R1–R5 | 0603/0805 电容电阻 | 工厂 | 去耦、I2C 上拉 4.7k ×4、MPR121 的 REXT 75k |
| J1 ToF 4P | JST SH 1.0 | 工厂 | **VL53L0X 模块贴在板正面丝印框里(板中下),镜头对准 W 窗**,30 mm 短线插 J1 |
| J2 麦克风 6 孔 | 焊盘 | 自己 | **INMP441 模块贴在板正面丝印框里(左中),正对 M 孔**,6 根 20 mm 短线焊到 J2(在 XIAO 右列下方;顺序 L/R·WS·SCK·SD·VDD·GND,同模块丝印) |
| J3 双屏 6P | JST SH 1.0,左边出线 | 工厂 | 3V3·GND·SDA0·SCL0·SDA1·SCL1,去眼罩的两块屏 |
| J4 电池 2P | JST PH 2.0 | 工厂 | 603040 锂电直接插 |
| J8 充电 2P | JST PH 2.0 | 工厂 | 与 J4 并联,去腔底 TP4057 的 B+/B−(它的 USB-C 对着 U 块) |
| J6 功放 5P | JST SH 1.0 | 工厂 | VIN·GND·BCLK·LRC·DIN,去腔底的 MAX98357A 模块 |
| J5 灯带 3P | JST SH 1.0 | 工厂 | VBAT·GND·DIN,可选 |
| J7 触摸 12 孔 | 2.0 mm 焊盘列 | 自己 | E0–E11,细线焊上去,通往各触摸方块的铜箔 |
| JP1 | 3 点焊接跳线 | 出厂已连 1-2 | 功放供电:默认 3V3;嫌音量小把中间点改连 VBAT |
| TP1 | 焊盘 | — | VBUS(XIAO 5V)测试点 |
| H1–H4 | M2 孔 | — | 接地环 |

全部元件在正面;背面只有走线和铺地,**背面贴电池**。

## 3 · 网络表(与洞洞板相同)

| 网络 | 连到 |
|---|---|
| 3V3 | U1.3V3 · U2 VDD · U3 VDD/VLOGIC · J1.1 · J2.5 · J3.1 · R1–R4 · JP1.1 |
| GND | U1 GND · 所有 GND 脚/EP · J4.2 · J8.2 · J5.2 · J6.2 · 连接器 MP 脚 · 安装孔环 |
| VBAT | TP2(← XIAO BAT+)· J4.1 · J8.1 · J5.1 · JP1.3 |
| VBUS | U1.5V → TP1(不供电) |
| SDA0 / SCL0 | U1 D4/D5 · U2 · U3 · J1.3/4 · J3.3/4 |
| SDA1 / SCL1 | U1 D0/D7 · J3.5/6(右屏独占) |
| I2S BCLK/LRC/DIN | U1 D2/D1/D3 · J6.3/4/5 |
| MIC SCK/WS/SD | U1 D8/D9/D10 · J2.3/2/4 |
| LED_DIN | U1 D6 · J5.3 |
| AMP_VIN | JP1.2 · C3 · J6.1 |
| ELE0–11 | U2 脚 8–19 · J7.1–12 |

I2C 地址:总线 0 = 左屏 0x3C · ToF 0x29 · MPU 0x68 · MPR121 0x5A;总线 1 = 右屏 0x3C。
MPR121 的 IRQ 没接(11 个 GPIO 用完了),固件按 50 Hz 轮询触摸寄存器即可。

## 4 · 下单(嘉立创 / JLCPCB)

| 项 | 选 |
|---|---|
| 文件 | `facebrd_gerber.zip`;贴片再传 `facebrd_bom.csv` + `facebrd_cpl.csv` |
| 层数 / 板厚 | 2 层 / **0.8 mm** |
| 表面处理 | 沉金(邮票孔贴焊平整) |
| 数量 | 5 片,贴 2 片 |
| 贴片 | 贴 BOM 里的全部(含 XIAO、两颗芯片、连接器);J2/J7/JP1/TP 只是焊盘,不贴 |

**下单前必须核对的 3 件事:**
1. BOM 里带 `?` 的 LCSC 编号(75k 电阻、JST 连接器)是我凭记忆写的,在嘉立创元件库搜型号确认。
2. XIAO、MPR121QR2、MPU-6050 当天有没有货(MPU-6050 已停产,库存会变)。
3. 让嘉立创把 XIAO 的封装和它库里 C48405120 的封装对一下——我的邮票孔焊盘是按 21 × 17.5 mm、2.54 间距、两列相距 15.24 画的。

## 5 · 收到板子后

1. 空板蜂鸣挡:3V3↔GND、VBAT↔GND、SDA0↔SCL0、SDA1↔SCL1 全部不响
2. 若 XIAO 自己焊:先单独插 USB 跑 `bench-check` 确认是好的(焊上拆不下来);邮票孔先焊对角两个定位
3. XIAO 背面 BAT+/BAT− 各焊一根 28AWG,穿过缺口,从板背面焊进 TP2/TP3
4. 插 USB:3V3 对 GND 量 3.3 V;各芯片不烫
5. 插 J3(双屏)、贴 ToF 模块插 J1、贴麦模块焊 J2,烧 `bench-check`:总线 0 报 0x3C·0x29·0x68·0x5A,总线 1 报 0x3C
6. 插 J6(功放),烧 `bench-audio`:喇叭音阶响,串口电平条随说话跳
7. 焊 J7 触摸线到铜箔;最后接电池 J4、充电线 J8,拔 USB,整机由电池点亮

## 6 · 已知取舍与后续

- **ToF、麦克风仍用模块**(贴在板正面):裸芯片的封装/引脚我没法百分百确认,v1 先稳。v2 再上板。
- **W 窗孔建议从 Ø6 放大到 Ø8**:模块现在离脸皮背面约 4–5 mm,加上 12 mm 方块,光路通道变长,Ø8 不会削测距视角(`kit_cubes.py` 的 W 半径 3→4)。
- 触摸线、眼屏线、功放线都是短线束,长度按各自机器人裁。
- 触摸方块(表面 1.5 mm 薄壁 + 内贴铜箔 + 背面线孔)在积木生成器里实现,见 `touch_plan.py` 的规划结果。
