# 元件焊接指导(MC02-AB 合板 · 配合 mc02_ab_sheet.png 使用)

图纸管"焊在哪",这份管"怎么焊、焊哪几针"。按顺序走,每步末尾有验收标准。

> v0.2 变化:A/B 两块 55×48 合并为 **一张 55×60 合板(MC02-AB)**,
> 用 4×M2 锁在 MC02-P 背板的 Ø6×9 柱上;电池 603040 魔术贴在板后
> 凹槽,喇叭面朝下放底排网孔块,TP4057 平放腔底、USB-C 口朝下对
> U 块通槽。双屏**不改地址**(都 0x3C),走两条 I2C 总线。

---

## 0 · 准备

- 烙铁 320–350°C(有铅锡)/ 360–380°C(无铅);锥形或马蹄头
- 松香助焊剂、吸锡带、斜口钳、镊子(TP4057 那包送的就行)
- 万用表(蜂鸣挡 + 直流电压挡)
- 洞洞板裁 55×48 两块(21×18 孔),断口锉平
- **原则:每个模块先单独焊好排针 → 面包板验货 → 再落板**

## 1 · 通用手法

- **排针**:先焊对角 1 脚 → 检查垂直、歪了加热扶正 → 再焊其余
- **母线**:一根镀锡裸线(剪电阻脚也行)沿孔排拉直,每 3-4 孔点焊一次
- **飞线**:28AWG 硅胶线,剥 2mm,先镀锡再焊,走线贴板面
- 每焊完一个模块:蜂鸣挡量 **VCC↔GND 不通** 才继续

## 2 · 模块预处理(逐个)

### SSD1306 屏 ×2(4 针:GND·VCC·SCL·SDA)
- 排针从**背面**插、正面焊,屏面朝外不挡视线
- **地址不用改**:两块都 0x3C,左屏挂总线 0(D4/D5),右屏挂总线 1(D0/D7)
  ——和面包板阶段的双总线方案一致,固件 `TWO_BUS=1` 已按此写好
- 验收:面包板点亮出 logo/花屏都算活

### VL53L0X 激光测距(只焊 VIN·GND·SDA·SCL 四针)
- XSHUT/GPIO1 留空不焊
- 出厂保护膜:装配对窗前再撕

### INMP441 麦克风(6 针:VDD·GND·SCK·WS·SD·L/R)
- **L/R 直接飞线到 GND**(定左声道),可在模块上就近焊
- VDD 接 **3V3**,不能接 5V

### MAX98357A 功放(排针 7 针 + 喇叭焊盘)
- 排针:VIN·GND·BCLK·LRC·DIN(GAIN、SD **悬空不焊**=9dB 增益、单声道混合输出,正合适)
- 喇叭:JESSINIE 3020 两根引线直接焊到板上 `+`/`−` 焊盘(或螺丝端子)
- VIN 接 3V3(音量够;后期嫌小再改 5V)

### MPU6050 姿态(只用 VCC·GND·SCL·SDA 前 4 针)
- 后 4 针(XDA/XCL/AD0/INT)留空;AD0 悬空 = 地址 0x68

### MPR121 触摸(VCC·GND·SCL·SDA + 电极线)
- 电极:一根线接到 0-11 任一通道,末端贴铜箔即触摸点,先接 1 路验证

### TP4057 充电板(不焊排针,直接焊线)
- `B+`/`B−` → 电池线(红/黑,先焊板端,**电池到货验完极性再接**)
- `OUT+`/`OUT−` → H5 线去 B 板
- USB-C 口朝外,先别沾锡弄脏舱窗对位面

### WS2812B 灯带(可选,H7)
- 剪 3-5 颗一段,焊 5V·GND·DIN 三根线;**认准箭头方向**,DIN 是输入端

### XIAO ESP32-S3(装舱版主控)
- **B 板上焊两条 7P 排母座,XIAO 插上去,不要直焊**——烧录、换板可拔
- 面包板阶段用你的 WROOM-32,它不落板

## 3 · 引脚速查

### 面包板验货(WROOM-32,M0 固件已用此映射)

| 信号 | WROOM GPIO |
|---|---|
| I2C SDA / SCL | 21 / 22 |
| 麦 SCK / WS / SD | 14 / 15 / 32 |
| 功放 BCLK / LRC / DIN | 26 / 25 / 27 |
| WS2812 DIN | 13 |

### 装舱(XIAO ESP32-S3,合板走线按这个)

| 信号 | XIAO 引脚 |
|---|---|
| I2C0 SDA / SCL(左屏·ToF·MPU·MPR) | D4 / D5 |
| I2C1 SDA / SCL(右屏,同为 0x3C) | D0 / D7 |
| 功放 BCLK / LRC / DIN | D2 / D1 / D3 |
| 麦 SCK / WS / SD | D8 / D9 / D10 |
| WS2812 DIN | D6 |

总线 0 上四个地址互不冲突:左屏 0x3C · ToF 0x29 · MPU 0x68 · MPR121 0x5A;
右屏独占总线 1(0x3C)。

## 4 · 落板顺序(对照 mc02_ab_sheet.png)

1. **合板**:先四角 M2 孔试装到背板柱上确认无碰 → SDA/SCL(×2 组)+ 3V3/GND 母线 → XIAO 两条 7P 排母座 → MAX98357A、MPU6050、MPR121 落板 → 模块飞线上母线 → JST 插座 J1-J5(右缘一列)
2. **腔底件**(不上板):TP4057 平放腔底、USB-C 朝下对准 U 块通槽,双面胶固定;喇叭面朝下压 G 块网孔,引线上 MAX 焊盘;电池魔术贴进板后凹槽
3. **远端模块**:VL53L0X 贴前壁 W 窗块后方、INMP441 对 M 孔块,飞线走 J1/J2;双屏在眼罩内,H3 排线走 T 块通道回 J3
4. **线束 H1-H7**:芯数/走向见图纸右下表,两端可拆

## 5 · 上电前检查(一条都不能跳)

1. 目检:放大看每个焊点,重点母线交叉处有无桥连
2. 蜂鸣挡:**3V3↔GND 不通、5V↔GND 不通**
3. 首次上电只插 USB(不接电池):摸各模块 3 秒,无烫手
4. 跑 I2C 扫描程序(bench-check 双总线版):总线0 报 0x3C·0x29·0x68·0x5A,总线1 报 0x3C
5. 电池到货:万用表量插头极性 → 对照 TP4057 丝印 `B+/B−` → 再插

## 6 · 常见翻车对照

| 现象 | 先查 |
|---|---|
| I2C 扫不到某地址 | 该模块 VCC/GND 反了?SDA/SCL 交叉了? |
| 两块屏只亮一块 | 右屏的 SDA/SCL 没接到 D0/D7(总线1)|
| 功放沙沙响 | GND 没共地 / DIN 线太长贴着电源线走 |
| 麦无信号 | L/R 悬空没接地;SD 线接错脚 |
| 模块发烫 | 立即断电,查 VCC-GND 短路 |
