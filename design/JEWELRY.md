# Mycelium 首饰线:耳饰 / 项链坠 / 小挂件

同一句话 → 同一只孢子 → 同一个孢子号。网页里长出来的那只生物,
做成一块真正的**马赛克**:底板是一格一个口袋的托盘,格与格之间有灰缝墙;
每种颜色就是一堆一模一样的小方片,照拼装图自己一格一格放进去,点胶固定。
生成器:`scripts/spore_jewel.mts`(与 `spore3d.mts` 共用引擎、哈希和编号)。

**形状与配色都跟网站一致**:
- 形状 = 引擎 `buildMosaic` 实际画出来的格子,抖动留空的格就是空的(和 `spore3d` 一样),
  不用轮廓包络补底色;只在外圈加一道 0.6 mm 细边当口袋壁。(`--plate-fill mask` 可切回整轮廓。)
- 颜色 = 这只孢子自己的调色板(家族色相 + 句子带来的第二色相 + 强度),压成 2 卷耗材取均色;
  底板 = 它最深一档再压暗。不同句子就是不同形象、不同颜色,目录里每张卡都是一只。
- 需要跨作品批量时用 `--spool-map family`:六个家族各一组固定色卷(由引擎 FAMILY 表推出)。

```
npx tsx scripts/spore_jewel.mts --text "轻轻地生长" --piece pendant            # 马赛克:底板 + 每色一种小方片 + 拼装图
npx tsx scripts/spore_jewel.mts --text "…" --mode assembly                      # 同色连片成一块镶片(零件少,马赛克感弱)
npx tsx scripts/spore_jewel.mts --text "轻轻地生长" --piece earring            # 自动镜像一对 _L/_R
npx tsx scripts/spore_jewel.mts --text "…" --piece charm --spools "#f2a7b8,#8ec5e8,#f6e7a1" --plate "#3b3a4a"
                                                                                # 固定耗材色,整批共用
npx tsx scripts/spore_jewel.mts --text "…" --mode relief                        # 旧的一体浮雕件(单色机 / 多色机 --split)
npx tsx scripts/spore_jewel.mts --text "…" --loop hole                          # 激光切亚克力:钻孔代替圆环
```

输出在 `out/jewel/<名字>*`:

| 文件 | 用途 |
|---|---|
| `_plate.stl` | 底板托盘(每格一个口袋 + 灰缝墙 + 外缘 + 圆环 + 背面编号),用底板色打印 |
| `_tile_<色>_h<档>.stl` | **一片**该色该高度的方片,放在原点;按 `_parts.txt` 的数量复制打印(同色同档的片完全相同) |
| `_c0.stl` `_white.stl` … | 该色所有方片原位摆放(看组装效果用) |
| `_map.svg` | **拼装图**:网格带列字母 / 行号,每格"颜色字母 + 高度数字"(如 B2),图例列出每色每档片数和耗材名 |
| `_parts.txt` / `_parts.json` | 零件清单:文件 → 耗材色/名 → 片数 → 单片尺寸(json 给批量脚本用) |
| `catalog/catalog-*.png` `.html` | `jewel_catalog.mts` 生成的配色目录 |
| `_assembled.stl` / `.ply` | 组装效果(看的,不是打的);`.ply` 带颜色 |
| `.svg` | 正面图纸(mm),`#cut` 层是轮廓+孔,给激光/亚克力 |
| `.json` | 尺寸、重量、零件数 |
| `_views.svg` | **三视图**:国标第一角画法,A4 横版,主视图 / 俯视图 / 左视图 + 尺寸(总宽高厚、环内外径或孔径、格与间隙)+ 明细表(零件 → 耗材名/色/片数)+ 标题栏;比例自动取 5:1…2:1。`--no-views` 关 |

## 1 · 结构(`--mode mosaic`,默认)

```
            ┌─ 眼白片 +0.3                      ← 比其他镶片再高一点,脸在单色下也读得出
   ┌────┐   │  ┌────┐┌──┐    ┌────┐
   │ 镶片 │   ▼  │    ││瞳│    │    │          ← 镶片:底板色以外的每个色块,高出底板 relief
═══╧════╧══════╧════╧╧══╧════╧════╧═══  底板顶面 BASE
   口袋 pocket 深 0.6 ──────────────────       ← 镶片坐进口袋,四周各留 fit=0.1 间隙
════════════════════════════════════════  底板底面(贴床面),背面阴刻孢子号
```

| 件 | 做法 | 默认 |
|---|---|---|
| 底板 | 只覆盖实际填色的格 + 外圈 `--rim` 0.6 mm 细边(口袋壁);抖动留空处是通孔,和网站一样。马赛克模式做薄:托盘 1.0 / 0.9 / 0.8 mm | 吊坠 1.0 / 挂件 0.9 / 耳饰 0.8 mm(assembly / relief:1.6 / 1.4 / 1.2) |
| 口袋 | **每格一个**方口袋,深 `--pocket`,口袋底下至少留 0.5 mm;格间灰缝墙宽 `--grout`,与底板顶面齐平。片靠墙定位,所以口袋可以浅 | 0.4 / 0.4 / 0.35 mm · 缝 0.4 mm(0.2 喷嘴两条线) |
| 方片 | 每格一片,边长 = 格 − 缝 − 2×fit;同色全部相同 | fit 0.1 → 吊坠 2.0 mm 方,挂件 1.6,耳饰 1.2 |
| 格大小 | 马赛克模式按件预设格,不按总高(片太小没法拿) | 吊坠 2.6 / 挂件 2.2 / 耳饰 1.8 mm(`--cell` 可改) |
| 高度 | 方片分 `--heights` 档高(默认 3),顶面在底板上方 relief×1/3、2/3、3/3(吊坠 0.67 / 1.33 / 2.0 mm,片本身 1.07–2.4 mm 高);`--height-by edt` 按离轮廓边的距离分档(边缘矮、中心高,网站那种中间厚的体量),`band` 按明度(越浅越高),`flat` 全同高。边缘半透明格永远最矮,瞳孔最矮,眼白比最高档再高 0.3 | relief 2.0 / 1.6 / 1.4 mm |
| 眼睛 | 眼白、瞳孔各是 1 格的小嵌件(`--eyes own`);瞳孔只到浮雕一半,是个黑色小坑 | 吊坠 2.1 mm 见方,耳饰 1.2 mm |
| 圆环 | 从顶格中央长出、嵌入底板 0.8 mm,属于底板零件;内径 ≥ 2.4 穿 0.8 开口圈 | 与底板同厚 |
| 背面 | 孢子号 `MYC-XXXXXX` 3×5 像素字体阴刻,刻在口袋底之下;放不下时只刻后 6 位 | 深 ≤ 0.4 mm |

**0.2 喷嘴设置建议**:层高 0.08–0.1;镶片 2–3 圈外墙即可(1.2 mm 的瞳孔片正好 3 圈);
底板朝下、镶片底朝下,全部免支撑;马赛克托盘口袋底到背面只剩 0.5–0.6 mm,背面编号只刻 0.2 mm(两层),要字深就 `--base 1.2`。
`--fit` 是唯一需要试的参数:先打一块底板和一片镶片,紧了 +0.05,松了 −0.05。

## 2 · 颜色与批量

**先把颜色压少**,再拆件,零件数才可控:

| 开关 | 做什么 | 默认 |
|---|---|---|
| `--colors N` | 按明度分位把身体格压成 N 档,每档取均色 | assembly 2 档(+底板色) |
| `--spool-map inventory` | **本色 → 手上的卷**:每只孢子自己的调色板压成 N 档,每档就近落到 `design/filaments.json` 里的卷(Lab 色差、色相加权、保持明暗顺序);底板先选一卷贴近引擎"地面色"且不浅于身体的 | 有耗材库时默认 |
| `--spool-map auto` | **本色**:每卷 = 该明度档的均色,底板 = 最深档压暗。引擎原色,不对应实际耗材 | 无耗材库时默认 |
| `--spool-map family` | **家族色卷**:六组固定卷,定义在 `filaments.json` 的 `families`(按引擎 FAMILY 色相在手上的卷里选定,可改),每家族 1 底板 + N 身体色,整批共用 6 组卷 | — |
| `--spools "#…,#…"` | 自定义固定色卷(按明暗接管明度档);`--spool-map nearest` 改为就近取色 | — |
| `--plate "#hex"` | 底板耗材色(不填则取调色板最深一档再压暗) | — |
| `--eyes own / merge` | 眼白瞳孔独立嵌件 / 眼白并入最浅色、瞳孔并入底板(少 4 片) | own |
| 孤岛合并 | 四邻无同色的格并入周围多数色,去掉"一格一片"的碎件(`--no-smooth` 关) | 开 |

样本:三句不同的话,`--spools 粉/蓝/黄 --plate 深灰`,挂件尺寸——

| 零件 | 片数(每只) | 批量打法 |
|---|---|---|
| 底板(深灰) | 1 | 一盘排 20–30 块 |
| 粉 / 蓝 / 黄 镶片 | 各 1–5 片 | 同色所有作品的镶片一起打,一盘几百片 |
| 眼白 / 瞳孔 | 各 2 片 | 一次打 100 对备用,所有作品通用(同一 `--cell` 下尺寸一样) |

每只 6–8 个零件;终端打印 `N colours / M regions / P parts to glue`,调到自己接受为止。
`--colors 1` = 底板 + 单一身体色,靠高低差表现抖动,零件最少。

### 2.2 · 批量排产(`jewel_batch.mts`)

```
npx tsx scripts/jewel_batch.mts            # 读 design/jewel_batch.json,输出 out/jewel/batch/
```

`design/jewel_batch.json` 每行一款(句子 · 家族 · 件型 · 件数),脚本逐款生成后按单色打印机的习惯合盘:

| 输出 | 内容 |
|---|---|
| `plates/bed_plate_<底板色>.stl/.svg` | 这个颜色的所有底板排在一盘(4 mm 间距,超出自动分盘),预览图上标孢子号 |
| `tiles/bed_tile_<颜色>_N.stl/.svg` | 这个颜色的所有马赛克片排一盘;盘内按"方边长 × 高度"分块并标注,数量 = 全部款式汇总 × (1 + 备用比例) |
| `batch_manifest.md/.json` | 每盘内容、每块来自哪些款、每款的零件清单和拼装图路径 |
| `designs/<款>/` | 每款自己的全部文件(底板、单片、拼装图、三视图) |

样本清单 14 款(12 句话挂件 + 第一句的吊坠和耳饰):4 种底板色 → 4 盘底板;14 种颜色 → 14 盘片,
盘内 1–7 块。盘尺寸 `--bed 180`(可用区域 mm),备用 `--spare 0.1`。

## 3 · 三种件

| 件 | 目标高度 | 格大小 | 成品(样本) | 重量(PLA) |
|---|---|---|---|---|
| `pendant` 吊坠 | 32 mm | ~2.3 mm | 30×37×2.7 mm | ~1.4 g |
| `charm` 挂件 | 24 mm | ~1.6 mm | 20×28×2.4 mm | ~0.5 g |
| `earring` 耳饰(镜像一对) | 20 mm | ~1.4 mm | 18×24×2.1 mm | ~0.4 g / 只 |

`--size <mm>` 改目标高度(格大小随之算出),或 `--cell <mm>` 直接定格大小;`--base/--relief/--pocket` 改厚度。
格数随句子浮动(10–15 × 12–17),同一预设下不同句子大小略有差别——这正是"每句一只"的意思。
**要让眼睛嵌件通用,整批用同一个 `--cell`**,而不是 `--size`。

## 4 · 组装

1. 每色按 `_parts.txt` 的数量打印 `_tile_<色>.stl`(一盘几百片,0.2 喷嘴 2 圈墙即可),分色装小盒。
2. 底板口袋朝上放平,对着 `_map.svg` 一格一格放:列字母 a→ 右、行号 1→ 下、格内字母 = 颜色、数字 = 高度档(1 最矮)。
   同色不同高的片外观只差 0.4 mm,分色分档装盒别混;拿不准就把片侧立起来比一下。
3. 胶:口袋底点一丁点 UV 胶,摆满一行照灯一次;或全部摆好后整面刷稀 502。灰缝墙本身就是定位,片不会跑。
4. 做一对耳饰时 `_R` 是镜像件,拼装图也镜像,别拿错。
3. 想要玻璃面:整面罩一层 UV 滴胶,台阶变成水下马赛克。
4. 眼睛最后放:眼白片比其他高 0.3,瞳孔片矮 0.4,顺序错不了。

## 6 · 其他工艺(`--mode relief`,一体件)

- 单色 FDM 一体打印,瞳孔坑点黑漆;或多色机 `--split`,每色一个闭合 STL + `_colors.txt`。
- 光固化树脂:同一 STL,细节更锐。
- 激光切亚克力 / 木片:`.svg` + `--loop hole`,`#cut` 层切、`#art` 层 UV 彩印。
- 金属:`.stl` 送失蜡铸造,背面编号铸出即"内刻"。

## 7 · 已知取舍

- 圆环是与底板重叠 0.8 mm 的独立闭合壳,切片软件自动并集;送铸造前在 Blender 做一次布尔。
- 底板在"对角相触"格处共享一条竖边(与 `spore3d` 同样性质),闭合但非流形,切片无影响;镶片零件均为流形。
- `--mode assembly`(同色连片)口袋相邻连通,镶片靠彼此挤靠定位;马赛克模式每格独立口袋,无此问题。
- 马赛克模式零件多:吊坠约 110 片、挂件约 80 片、耳饰一对约 150 片。嫌多就 `--colors 1`(两色)或换 assembly 模式。
- 格小于 1.3 mm 时背面编号刻不下,自动跳过并提示 `id skipped`。
- 所有输出确定性:同一句话、同一参数,永远同一个文件。
